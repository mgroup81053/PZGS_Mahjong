마작 중앙판 1버전 — 3DWOX 1X / 1X DP302용 STL 내보내기

1버전 원본 형상을 변경하지 않고 내보냈습니다. 단위는 mm입니다.

[실제 출력에 사용할 파일]
mahjong_v1_full.stl
전체 크기: 130 x 130 x 8mm. 바닥은 Z=0이며 평평한 바닥을 베드에 둡니다.
STL은 색상과 프린터 설정을 저장하지 않는 형상 파일입니다.
이 파일은 전 색상 부품을 하나의 닫힌 형상으로 합친 단색 출력용입니다.
인레이와 글자 표면이 평평하게 합쳐져 색상 경계나 글자 선이 출력 표면에 남지 않습니다.
도색할 때는 함께 제공한 SCAD의 색상 미리보기와 참고용 색상 파일로 위치를 확인하세요.

[DP302에서 색상을 구현하는 방법과 한계]
DP302는 단일 노즐입니다. 이 디자인처럼 같은 층에 여러 색이 있는 배치를 자동 출력할 수 없습니다.
노란색 필라멘트로 전체를 출력한 뒤 녹색 바닥, 방위 배경과 글자를 도색하는 방식이 가능합니다.
층 사이 필라멘트 교체만으로는 현재 디자인의 여섯 색을 완성할 수 없습니다.
색상별 STL은 아래처럼 영역을 기록한 참고용입니다. 따로 출력해 끼우는 조립용으로는 설계하지 않았으며,
조립 공차가 없고 일부 글자는 여러 개의 분리된 작은 형상입니다. 그대로 접착 조립이 보장되지 않습니다.

reference_color_parts/01_yellow_body.stl: 본체 — 노랑 (#FFD10D)
reference_color_parts/02_green_tray.stl: 주사위 바닥 — 녹색 (#87B82E)
reference_color_parts/03_red_east_background.stl: 동 배경 — 빨강 (#D10A0F)
reference_color_parts/04_dark_gray_backgrounds.stl: 남서북 배경 — 짙은 회색 (#2E3036)
reference_color_parts/05_black_east_letter.stl: 동 글자 — 검정 (#050505)
reference_color_parts/06_light_gray_letters.stl: 남서북 글자 — 옅은 회색 (#D1D4D9)
색상 코드는 원본 미리보기 색을 환산한 값이며 실제 필라멘트/도료 색 일치를 보장하지 않습니다.
참고용 파일들은 원본과 같은 좌표에 있습니다. 높이 방향으로 베드 위에 떠 있는 부품도 정상입니다.
단색 전체 출력 시에는 full.stl 하나만 불러오세요. 전체 파일과 분할 파일을 동시에 넣으면 중복됩니다.

[3DWOX Desktop에서 준비]
프린터에서 1X / 1X DP302를 선택하고 full.stl을 불러오세요.
배율 100%, 치수 130 x 130 x 8mm, 바닥 Z=0을 확인하세요.
PLA를 사용할 경우 설치된 PLA/카트리지에 맞는 제조사 기본 프로필을 출발점으로 사용하세요.
시작 설정 제안: 레이어 0.2mm, 벽 3줄, 상하단 두께 1.2mm 이상, 인필 20%, 서포트 끔.
이는 실출력 검증된 장비 프로필이 아니므로 장비 담당자가 슬라이스 결과를 확인해야 합니다.
슬라이싱 후 장비용 G-code를 생성해야 하며 STL만으로 바로 출력 버튼을 누를 수는 없습니다.
